# 开发路线图

> 原则：**先做对一件核心闭环，再做全方位**。每个里程碑都可独立运行、可验证、可回滚。三端共享一套代码基座。

## M0 项目脚手架 & Flutter 三端骨架

**目标**：项目能跑起来，三端都有可运行壳。

- [x] 项目文档（本文档即产物之一）
- [ ] Flutter 项目初始化（全平台：iOS / Android / macOS / Win / Linux）
- [ ] 响应式 UI 骨架：断点布局（phone / tablet / desktop），`SafeArea` + 横竖屏
- [ ] 持久层：SQLite 抽象（drift）+ 迁移脚本
- [ ] LLM Provider 抽象（本地/远程 mock）
- [ ] 语音层骨架：`SpeechToTextProvider` + mock
- [ ] 日志与配置
- [ ] `core/` 目录结构与纯 Dart 单测脚手架

**验收**：三端都能启动，显示出自适应主界面；跑的 `alfred run` 能接收文本（mock 语音）并 echo；写读 SQLite 通过。

## M1 核心闭环：日程与提醒（P0）+ 语音

**目标**：让"管家"第一件事靠谱 —— **提醒真的会被执行，且用语音能创建**。

- [ ] 日程技能：CRUD + 重复事件 + 提醒偏移
- [ ] 自然语言解析：语音/文本 `明晚7点健身房` → Schedule（LLM + 校验兜底）
- [ ] 本地提醒调度器（平台原生通知）
- [ ] 执行前确认 + 撤销
- [ ] 零漏触发（启动补发）
- [ ] 语音输入闭环：本地 Whisper + VAD 接通日程技能
- [ ] 平板/桌面/手机三种尺寸 UI 都覆盖日程屏

**验收（User Story）**：
> 手机按住说"明早 8 点提醒我吃药" → 次日 8:00 收到通知 ✅
> 电脑端"周五 18:00 取消健身" → 取消并确认 ✅
> 平板横屏看今日日程大卡片 ✅

## M2 账号 + 多端同步（P0）

**目标**：Alfred 是三端一管家，数据流动起来。

- [ ] 账号系统（注册/登录/设备注册）
- [ ] oplog 变更捕获 + 上传/拉取
- [ ] 冲突解决（LWW + tombstone）
- [ ] 云端 relay 服务（轻量）
- [ ] 离线队列 + 网络恢复自动同步
- [ ] 多设备登录同账号后自动合并

**验收**：
> 手机新增日程 → 同一账号的平板自动出现 ✅
> 平板删除日程 → 手机尊重删除（tombstone 生效）✅
> 飞机模式期间在手机记一笔 → 开网后电脑出现该条 ✅

## M2 长期记忆与用户档案（P0）

**目标**：Alfred 开始"记住你"。

- [ ] Memory 技能：增删改查 + 语义检索（向量 + 摘要）
- [ ] 对话中自动抽事实（"我喜欢喝美式"）→ 归档
- [ ] 记忆修正（`忘记...` / `记住...`）
- [ ] 上下文注入每次对话
- [ ] 语音唤醒词（"Hey Alfred"）+ 静音自动切断
- [ ] 记忆参与同步（多端共享档案）

**重要约束**：记忆可查看、导出、清空（清空走 tombstone 同步）。

**验收**：
> 对话说"我喜欢喝美式" → 隔天问"我喝什么咖啡" → 回答正确 ✅
> "我不喜欢美式了" → 更新而非叠加 ✅
> 平板 Pro 上唤醒说"明天下午提醒交方案" → 全端可见 ✅

## M3：财务 + 生活辅助（P1）

**目标**：从记事本到生活工具。

- [ ] 记账：`买菜 128` 语音/文本入账
- [ ] 月度支出总结（分类汇总）
- [ ] 天气查询 + 通勤建议
- [ ] 购物清单
- [ ] TTS 回复朗读（可选，默认关）

**验收**：记账与手算一致；天气真实；平板/桌面可多栏展示月度图表。

## M4：健康（P1）

- [ ] 健康提醒（用药/维生素/喝水）复用日程
- [ ] 健康记录（体重/睡眠/运动）
- [ ] 健康仪表盘（列表/折线）

## M5：情绪陪伴（P2）

- [ ] 情绪识别与共情（低风险实现）
- [ ] 情绪日志 + 简单可视化
- [ ] 主动关怀 
- [ ] **危机检测安全网（P0 必须）**：识别自伤倾向，无条件给求助资源，不提供建议

## M6：打磨与发布

- [ ] 数据导出/导入（JSON）
- [ ] 断网降级全面验证
- [ ] 一键清除、关闭记忆
- [ ] 性能、崩溃采集、错误处理
- [ ] 三端商店包（App Store / Play / 桌面安装包）

## 风险清单

| 风险 | 缓解 |
|------|------|
| LLM 时好时坏 | 核心动作 LLM + 规则双重校验；不依赖模型做执行 |
| 提醒漏触发 | 本地调度器 + 启动补发；错误指标可追踪 |
| 多端同步冲突 | LWW/墓碑；冲突可查询；先本地一致再同步 |
| 语音识别错误 | 关键操作语音复述确认；可语音纠正 |
| 平台差异 | Flutter 一套代码，但各平台系统通知/权限差异需单独测 |
| 记忆幻觉 | 记忆可查询、修正、关闭 |
| 隐私 | 本地优先 + 端到端加密（P2）；导出/清空一键 |
