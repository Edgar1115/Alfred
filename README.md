# Alfred

> 你的私人生活管家。

Alfred 取自蝙蝠侠中那位忠诚、全能、永远靠得住的管家阿尔弗雷德（Alfred Pennyworth）。我们希望它成为你数字生活中的「阿福」—— 不只是一个提醒工具，而是一个认识你、关心你、帮你把生活打理得井井有条的全方位 AI 生活管家。

## 项目定位

Alfred 是一个**跨三端（电脑 / 手机 / 平板）的 AI 生活管家应用**：采用 **Local-first 架构**（数据存在本地 SQLite，多端通过账号自动同步），并采用 **Agent-native** 智能——**Agent 是系统唯一的智能决策核心**，日程、提醒、记忆、搜索、财务与设备等能力均以**结构化工具（Tool）**暴露给 Agent，由 Agent 根据用户目标动态规划、组合调用；**确定性执行、安全权限与持久化由 Agent 外部运行时保障**，辅以长期记忆系统沉淀对用户的持续理解。

- **语音优先，一直在听**：应用启动即常驻聆听，像对真管家一样开口吩咐；Alfred 会判别"该办的 / 该记的 / 废话"
- **语音为主，文本为辅**：平时开口说得最多，但想打字时随时一键切换；默认首屏语音，偏好设置里可改成文本优先
- **三端一管家**：同一账号、同一份记忆，电脑/手机/平板自动同步

## 两个版本（同源，双发行）

Alfred 面向两类用户，但**只有一套代码**：

| | **Community / 自托管版**（开源） | **Cloud / 大众版** |
|---|---|---|
| 目标用户 | 懂自部署的开发者、极客 | 大众用户，傻瓜式开箱即用 |
| 获取方式 | 开源发布（许可证待定），可自行编译 | 应用商店 / 官网下载 |
| 数据与账号 | 完全本地 + 可自建同步节点 | 官方托管账号 / 同步 / AI |
| AI 能力 | 自带 LLM API Key / 本地模型 | 云集成的 LLM / ASR |
| 能力边界 | **全量能力，无阉割** | 全量能力 + 官方托管便利 |

**关系**：两块共享 `core/`（业务逻辑、工具（Tool）、数据模型、同步协议）与三端 Flutter 客户端；差别仅在**基础设施由谁提供**——自托管版对接自带 Key / 自建服务，Cloud 版对接官方服务。通过 Provider / 配置注入区分，**不复制业务代码**。

> ⚠️ 开源许可证**待定**（倾向 AGPL-3.0 以便自托管与商业版本共存）。选定前文档先以"待定"标注。

## 核心能力

- **个人日程与提醒**：待办、日程、定时提醒、纪念日
- **语音输入（第一等公民）**：常驻聆听 + 语音转写 + 唤醒；Alfred 对每句话做**智能判断**——该办的去办（确认后执行）、该记的默默记下（通过记忆工具）、废话忽略
- **文本输入（平等可用）**：随时可打字，输入条一键切换语音/文本；默认语音首屏，偏好可改为文本优先
- **长期记忆与档案**：记住用户偏好、家人、工作等，包括常驻聆听中"静默吸收"的信息，跨端共享
- **财务与健康追踪**：记账、预算、体检/用药提醒
- **日常生活辅助**：天气、通勤、购物清单、菜谱等
- **情绪陪伴与心理关怀**：情感倾听、鼓励、轻量情绪记录，做你的心灵管家
- **多端同步**：电脑 / 手机 / 平板自动一致，断网可离线使用
- **通用对话**：任何其他你需要的帮助

## 设计原则

1. **可靠优先**：涉及时间、金钱、健康的核心动作，由 **Agent 外部的运行时 / 策略引擎（Policy Engine）确定性执行**，不依赖模型幻觉。**Agent 负责决策，运行时负责把关**。
2. **先决策，后执行**：智能表现在 Agent 理解用户、动态规划、组织表达；执行层永远是**工具调用 + 确定性运行时**。
3. **对话优先（Assistant-First）**：**Alfred 本身就是产品重心**。打开应用即是对话，查询、记录、汇总都在对话里完成；日程列表、记账本、记忆档案等管理界面**存在但刻意弱化**，仅作校对/纠错的后台。
4. **一直在身边（Always-Listening）**：启动即常驻聆听，由 **Agent 统一做智能判断**——识别"该办的"（去执行，经确认）、"该记的"（静默记入记忆）、"废话"（忽略）；透明可控（聆听指示 / 一键闭麦 / 可完全关闭）。
5. **输入可切换**：**语音为主、文本为辅**。默认首屏语音输入；输入条一键切语音/文本；偏好设置可选文本作为默认输入。
6. **隐私至上**：Local-first，数据存在本地设备，云端仅做账号/同步；记忆可导出、可清空。
7. **三端一体**：一套代码基座适配电脑 / 手机 / 平板，自适应 UI，同一账号自动同步。
8. **渐进式交付**：先跑通最小闭环，再逐步长出全方位能力。
