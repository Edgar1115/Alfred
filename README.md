# Alfred

> 你的私人生活管家。

Alfred 取自蝙蝠侠中那位忠诚、全能、永远靠得住的管家阿尔弗雷德（Alfred Pennyworth）。我们希望它成为你数字生活中的「阿福」—— 不只是一个提醒工具，而是一个认识你、关心你、帮你把生活打理得井井有条的全方位 AI 生活管家。

## 项目定位

Alfred 是一个**跨三端（电脑 / 手机 / 平板）的 AI 生活管家应用**：采用 **Local-first 架构**（数据存在本地 SQLite，多端通过账号自动同步），并结合**混合模式**智能——以 LLM 提供自然语言理解与深度对话，以结构化技能与规则系统确保日程、记账、提醒等关键动作的确定性执行，辅以长期记忆系统沉淀对用户的持续理解。

- **语音优先**：像对真管家一样开口吩咐
- **三端一管家**：同一账号、同一份记忆，电脑/手机/平板自动同步

## 核心能力

- **个人日程与提醒**：待办、日程、定时提醒、纪念日
- **语音交互（第一等公民）**：语音转写 + 唤醒词，说话即管事
- **长期记忆与档案**：记住用户偏好、家人朋友信息、重要事件，形成持续用户画像，跨端共享
- **财务与健康追踪**：记账、预算、体检/用药提醒
- **日常生活辅助**：天气、通勤、购物清单、菜谱等
- **情绪陪伴与心理关怀**：情感倾听、鼓励、轻量情绪记录，做你的心灵管家
- **多端同步**：电脑 / 手机 / 平板自动一致，断网可离线使用
- **通用对话**：任何其他你需要的帮助

## 设计原则

1. **可靠优先**：涉及时间、金钱、健康的核心动作，必须由规则引擎确定性执行，不依赖模型幻觉。
2. **先估算，后智能**：智能表现在理解用户、组织策略、生成表达上；执行层永远走结构化代码。
3. **隐私至上**：Local-first，数据存在本地设备，云端仅做账号/同步；记忆可导出、可清空。
4. **三端一体**：一套代码基座适配电脑 / 手机 / 平板，自适应 UI，同一账号自动同步。
5. **渐进式交付**：先跑通最小闭环，再逐步长出全方位能力。
